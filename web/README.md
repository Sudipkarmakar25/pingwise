# Pingwise web

The Next.js app for Pingwise. See the [main README](../README.md) for setup and architecture.

```bash
cp .env.example .env.local   # API_BASE_URL=http://localhost:8090
bun install
bun run dev                  # http://localhost:3100
```

Other scripts: `bun run build`, `bun run start`, `bun run lint`, `bun run type-check`.
